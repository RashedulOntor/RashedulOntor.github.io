# MD. Rashedul Islam (Rashedul Ontor) - Personal Portfolio 🚀

Welcome to the repository of my personal portfolio website. This project showcases my journey as an Android App Developer, a Computer Science & Engineering student, and an Educator. 

🔗 Live Demo: [rashedulontor.github.io](https://rashedulontor.github.io)

## ✨ Key Features
*   **Modern UI/UX:** Premium Glassmorphism (frosted glass) design with a clean, responsive layout.
*   **Dark/Light Mode:** Interactive theme toggle that saves user preference.
*   **Dynamic Typing Effect:** Integrated `Typed.js` for an engaging hero section.
*   **Functional Contact Form:** Visitors can send messages directly to my email using Formspree.
*   **Interactive Sections:** Smooth scrolling, tabbed "About Me" section, and hover animations.
*   **Live Wallpaper Support:** Optimized to be used as an interactive desktop wallpaper via Lively Wallpaper.

## 🛠️ Technologies Used
*   **HTML5:** For semantic and structured content representation.
*   **CSS3:** Custom styling, Flexbox, CSS Grid, animations, and responsive media queries.
*   **JavaScript (ES6):** DOM manipulation, theme toggling, scroll events, and intersection observers for scroll-reveal animations.
*   **FontAwesome:** For intuitive UI icons.
*   **Google Fonts:** Utilizing 'Poppins' for a professional and modern typography experience.

## 📂 Sections Included
1.  **Home:** Engaging intro with a dynamic typing effect and social links.
2.  **Services:** Highlighting my offerings in Android App Development and Teaching/Mentoring.
3.  **Experience:** Showcasing my leadership roles as the Founder of Dream Up Academy and Director of Prottoy Academy.
4.  **Projects:** Links to my latest GitHub repositories and tech developments.
5.  **Achievements:** Milestones including Govt. exam success and sports championships.
6.  **Reviews:** A dedicated section for student and client testimonials.
7.  **Contact:** Formspree-powered contact form and direct WhatsApp integration.
8.  **About Me:** Detailed tabbed view of my education, experience, and leadership history.

## 🚀 How to Run Locally
If you want to explore the code or run this portfolio on your local machine:
1. Clone the repository: `git clone https://github.com/RashedulOntor/RashedulOntor.github.io.git`
2. Open the project folder in your favorite code editor (e.g., VS Code).
3. Open `index.html` using a Live Server extension to view it in your browser.
